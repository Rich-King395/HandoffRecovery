# 本地运行记录

这里只保存 HandoffRecovery 自身的联调与方法运行记录。本目录除本说明外默认由 Git 忽略。

后续记录应能关联原始任务、所用模型与代码版本、恢复输入和输出、GUI 决策计数，以及云端调用次数、token 和耗时；图片按调试需要保留，凭据不写入记录。

HandoffBench 的原始评分和历史结果继续保存在其自身目录。方法记录可以引用对应结果，但不得覆盖或重新解释评分为已通过。人工控制权通知的联调记录应明确标注用途，不能混入自动正式批测。

正式批量报告还应区分外部任务成绩和恢复方法指标：有效接管率、接管触发率、恢复覆盖率、共享决策预算耗尽率、Planner 调用次数、`EXECUTE`/`VERIFY`/`FALLBACK` 分支分布、查证轮数、交付后的云端调用数，以及 Planner/执行器错误试次。报告还按 HandoffBench 冻结元数据列出五种接管类型的恢复成功率和各 App 的任务成功率。恢复成功率的标准分母是有效接管数；覆盖率使用全部计划试次作为参考，不能替代标准恢复率。
